# Пушкин. Болдинская осень

Веб-презентация к уроку литературы о Болдинской осени 1830 года: почему Пушкин оказался заперт в Болдино, что он там написал и почему эти три месяца считаются главными в его жизни. 15 слайдов.

Презентацию подготовили **Алиса Гарловская** и **Влад Всемогущий**.

## Как смотреть

- стрелки, пробел, колесо мыши или свайп — листать;
- **F** — полноэкранный режим; **P** — печать или сохранение в PDF;
- клик по полоске внизу — прыжок к слайду; адрес `#9` открывает девятый слайд.

С телефона: слайд показывается целиком между крупными кнопками, свайп листает, ☰ открывает содержание, нажатие на фото — полноэкранный просмотр, двойной тап — спрятать или вернуть панели.

Сайт статический: HTML + CSS + JS, шрифты Cormorant Garamond и PT Serif лежат в `fonts/`.

## Локальный запуск

```bash
python -m http.server 8000
# открыть http://localhost:8000
```
